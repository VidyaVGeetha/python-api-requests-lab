# API Fundamentals — Working with HTTP Requests in Python

This project is a hands-on learning lab completed as part of the IBM Python programming course.  
The notebook demonstrates how to work with HTTP GET and POST requests using the Python `requests` library, 
including handling parameters, headers, JSON responses, and saving downloaded files.

## 🧩 Project Overview

In this lab, I practiced:
- Sending **GET requests** with query parameters
- Sending **POST requests** with form data
- Viewing and interpreting **request & response headers**
- Understanding **request body vs response body**
- Working with **JSON responses (`r.json()`)**
- Downloading and saving an **image file**
- Opening images using **Pillow (PIL)**
- Comparing behavior of **GET vs POST requests**

The practice examples use the **httpbin.org test API** and image resources provided in the IBM learning platform.

## 📑 Key Learning Concepts

- What happens when a GET vs POST request is made  
- How data is passed through:
  - URL parameters (`params`)
  - Request body (`data`)
- How to inspect:
  - `r.headers`
  - `r.status_code`
  - `r.text` and `r.json()`
- How to download and save files programmatically
